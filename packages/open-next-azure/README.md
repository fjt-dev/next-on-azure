# opennext-adapter-azure

Azure adapter for [OpenNext](https://opennext.js.org/aws): run Next.js on Azure Functions (Flex Consumption) with Blob, Table and Queue Storage and Azure Front Door.

> **Legacy.** This is the first, OpenNext-based package of the project; the project moved to `packages/next-on-azure` (ADR-0017) and this package will be removed. Experimental, pre-release, not yet published. This is a community adapter and **not an official OpenNext package**.
