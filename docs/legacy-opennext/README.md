# Documentation of the OpenNext-based package (legacy)

These pages describe `packages/open-next-azure` (package name `opennext-adapter-azure`), the first design of this project, which runs Next.js through `@opennextjs/aws` with a set of OpenNext overrides. The project moved to a design without `@opennextjs/aws` ([ADR-0016](../plan/decisions.md), [ADR-0017](../plan/decisions.md)); the new documentation is one level up. This old package and these pages stay until it is removed (migration stage 5), and they are not updated any more.
